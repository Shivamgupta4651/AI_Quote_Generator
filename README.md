# AI Quote Generator

## Description

A web application that fetches and displays random quotes from an AI-powered API. The app includes a "Get Quote" button, which triggers fetching of a new quote. It has a loading state while fetching and gracefully handles errors.

### Features
- Fetches random quotes from the **Quotable API**.
- Interactive "Get Quote" button with a loading state.
- Responsive design for all screen sizes.
- Error handling in case of API failure.
